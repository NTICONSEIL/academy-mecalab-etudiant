# MecaLab — Python pour la mécanique
CESI • Prépa 1

## Démarrer
Clonez le dépôt avec `git clone URL_DU_DEPOT` (remplacez le paramètre par l'URL communiquée par l'enseignant). Ouvrez le dossier dans VS Code.

```bash
python --version
python -m pip install -r requirements.txt
```
Sous Windows, `py` peut remplacer `python`. Sélectionnez le même interpréteur dans VS Code.

Ouvrez [RoboLab — séance 1](RoboLab/seance_01/README.md). Copiez le dossier `exercices` dans `mon_travail` à la racine avant de modifier les scripts. Lancez-les depuis ce dossier. Les fichiers personnels sont ignorés par Git ; `git pull` permet de récupérer les nouveaux supports.

Le projet est une simulation pédagogique, pas un contrôleur de robot réel.
