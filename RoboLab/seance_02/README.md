# RoboLab — Séance 2 : cinématique inverse

Durée : 4 h. Classe préparatoire, première année. Robot R2 : 40 cm et 30 cm.

- [Cours](cours.md)
- [TP étudiant](tp.md)
- [Scripts de départ](exercices/)

Installer Matplotlib : `python -m pip install matplotlib`.
Copier les dix scripts ensemble dans `mon_travail/seance_02`, puis ouvrir ce dossier dans VS Code. Exécuter les scripts dans l'ordre, par exemple `python ex01_accessibilite.py`. Les fonctions incomplètes lèvent volontairement `NotImplementedError`. Les imports ne déclenchent pas les démonstrations grâce à `if __name__ == "__main__"`.

EX01–08 obligatoires ; EX09–10 approfondissement. Le modèle direct de S1 est fourni dans EX06 pour rendre cette séance autonome. Aucun matériel réel requis.
