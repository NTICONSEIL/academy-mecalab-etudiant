# Protocole série v1
115200 bauds, 8N1, ASCII, fin LF (CR ignoré). Après ouverture attendre le redémarrage Uno. Les lignes commençant par # sont des messages de statut. Trames : `time_us,count,theta_rad,omega_rad_s,setpoint_rad,pwm,error_rad` (7 champs). PWM signé entier −255..255. Horodatage micros() uint32 : débordement après environ 71,6 min ; limiter chaque essai à quelques secondes, rejeter les ruptures temporelles.

Sketch 01 : `time_us,adc` ; sketch 02 : `time_us,count` ; sketches 03/04 : trame complète. Commandes 03/04 : `CONFIG,cpr,sign,max_pwm,max_angle_rad` (cpr mesuré, signe ±1, PWM plafond 1..100, course relative 0..π), `MODE,OPEN` ou `MODE,PID` (04 uniquement), `PWM,30`, `SETPOINT,0.2` (radians), `GAINS,kp,ki,kd`, `START`, `KEEP`, `STOP`. Configurer à l'arrêt ; origine relative au CONFIG. START exige configuration et mode explicite ; KEEP toutes les 100 ms ; arrêt après 500 ms sans KEEP ou après 5 s de marche. STOP désactive STBY. Pas de redémarrage automatique. Les consignes et gains ne changent qu'à l'arrêt. Vérifier chaque ACK avant START. La télémétrie est à 25 Hz, la commande à 100 Hz. Une acquisition peut perdre des lignes : analyser les timestamps. Les gains sont en unités PWM normalisé/rad, etc., pas en N·m.
