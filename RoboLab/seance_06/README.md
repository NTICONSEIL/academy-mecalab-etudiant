# RoboLab S6 — Du modèle au banc réel

Prépa CESI — 4 h, binômes. Prérequis : S1–S5, fonctions Python, dérivation et Euler.

**Démarrage sans matériel (recommandé)** : `python -m pip install -r requirements.txt`, puis `cd exercices` et `python ex01_capteur_analogique.py`. Compléter les TODO dans l'ordre. Les données sont synthétiques, jamais des mesures réelles.

Avec matériel : lire impérativement [materiel.md](materiel.md), [montage.md](montage.md) et [protocole_serie.md](protocole_serie.md). Faire valider le banc par l'enseignant avant toute mise sous tension moteur. Les sketches sont des prototypes non validés sur carte.

- [Cours](cours.md) — [TP](tp.md)
- 10 scripts étudiants, 3 supports, 4 sketches Arduino, 10 SVG, 8 CSV synthétiques.
- EX01–08 obligatoires ; EX09–10 approfondissements.

Livrable : scripts complétés, figures légendées, CSV et métadonnées, synthèse modèle/réel. Ne jamais présenter une simulation comme une mesure.
