# Données exclusivement synthétiques
Générées avec support_simulation.py (Euler explicite, K=8 rad/s par commande normalisée, tau=.25 s, dt=.01 s, C=2400, graine 6). Les réponses PWM 60/100/150 sont virtuelles et sans limite de course. Les réponses P/PI/PID utilisent respectivement (1,0,0), (1,.3,0), (1,.3,.15), consigne .5 rad, saturation .35. Ces gains ne sont pas des réglages matériels. Le bruit capteur est synthétique (écart-type 1 comptage), étalonnage idéal. Télémétrie virtuelle 100 Hz, réelle 25 Hz. Créer un dossier `reelles/` séparé avec date, référence moteur, CPR, tension, gains, charge, fréquence et opérateur. Ne pas écraser les données synthétiques.
