# EX11 — Optimisation de la commande R2
Exécuter `python ex11_optimisation.py` pour reproduire la grille (72 configurations). Le notebook autonome contient les supports et les courbes. Dépendance graphique : matplotlib. Les seuils de précision sont des hypothèses pédagogiques, non des spécifications industrielles. Le profil cubique est le meilleur sur la grille selon durée puis RMS ; le quintique est recommandé pour sa marge en accélération. Les actions de saisie et dépose restent programmées, sans collision ni impact. La perturbation reste fixée à 5–6 s, donc sa phase relative change avec la durée. Les gains ne sont pas certifiés robustes ; le cas 700 g échoue aux critères. Le remplacement temporaire du profil dans le module support est prévu pour une exécution séquentielle uniquement.
